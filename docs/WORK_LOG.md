# Журнал выполненных работ

Этот файл — постоянный журнал изменений проекта. Для каждой отдельной задачи или серии связанных изменений добавлять запись с датой и ссылкой на PR/коммит.

## Обязательный формат записи

- **Что требовалось:** исходная задача и ожидаемый результат.
- **Что сделано:** конкретные изменения и затронутые файлы/компоненты.
- **Как сделано:** способ реализации, важные решения и ограничения.
- **Проверки:** тесты, CI, ручные проверки и их фактические результаты.
- **Что не получилось / осталось:** невыполненное, блокеры, неподтверждённые предположения и следующие действия.
- **Публикация:** что попало в production, что осталось только в ветке/PR.

Не отмечать проверку как успешную, если она фактически не запускалась. Отделять автоматические smoke/CI-проверки от ручной проверки в браузере. Не записывать в этот публичный файл пароли, токены, секреты, приватные адреса электронной почты, персональные данные и другие чувствительные значения. Для таких сведений фиксировать только факт наличия/подтверждения и хранить точное значение вне публичного репозитория.

## 2026-11-21 — Сведения оператора и безопасное обращение с контактным адресом

- **Что требовалось:** продолжить подготовку черновика политики конфиденциальности; зафиксировать предоставленные владельцем сведения и единственный планируемый контактный адрес; сделать ход работы и ограничения понятными.
- **Что сделано:** в черновике и checklist зафиксировано предоставленное владельцем ФИО. Отмечено, что владелец передал один контактный адрес для будущих обращений, но его точное значение не хранится в публичном репозитории. Уточнено, что технический отправитель писем Resend не является адресом для входящих privacy-запросов. Добавлен этот журнал как обязательная история работ.
- **Как сделано:** изменения ограничены файлами `docs/legal/privacy-policy-draft.md`, `docs/legal/privacy-policy-release-checklist.md` и этим файлом. После выявления риска раскрытия персонального адреса в публичном PR ветка была возвращена к версии до добавления точного адреса; затем документы обновлены без публикации его значения. Описание PR также должно содержать только факт предоставления контакта, но не сам адрес.
- **Проверки:** проверено актуальное содержимое файлов ветки и diff PR: точный контактный адрес в текущем содержимом не должен присутствовать. Предыдущая CI-проверка PR до этих последних документальных правок была успешной; проверки нового head commit необходимо дождаться отдельно.
- **Что не получилось / осталось:** входящая доставка и контроль почтового ящика не проверялись. Нельзя гарантировать удаление уже опубликованного адреса из всех GitHub-кешей, ранее созданных клонов, форков или внешних архивов. Правовой статус оператора, страна, адрес, целевые страны аудитории и применимые обязанности остаются неподтверждёнными.
- **Публикация:** публичная страница политики не создавалась; production, база данных и настройки сервисов не менялись. Изменения остаются в PR #49 до прохождения актуальных проверок и объединения.
