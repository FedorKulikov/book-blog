# Ключи доступа (passkeys)

Passkeys добавляют независимый способ входа: пользователь может забыть пароль и потерять резервные коды, но войти с заранее зарегистрированным ключом доступа. После входа он сможет сменить пароль и выпустить новый комплект кодов.

## Ограничения

- Passkeys в Supabase Auth пока помечены как experimental; API может измениться.
- Это дополнительный фактор, а не универсальная процедура восстановления. Если пользователь потерял пароль, все резервные коды и все зарегистрированные passkeys, автоматическое восстановление по-прежнему невозможно.
- Регистрация ключа требует действующей сессии.
- Доступен только production-домен, указанный как WebAuthn RP origin.
- Не меняйте RP ID после регистрации пользователями ключей: это сделает существующие ключи непригодными для входа.

## Включение в production

1. В Supabase откройте **Authentication → Passkeys**.
2. Включите **Enable Passkey authentication**.
3. Установите:
   - **Relying Party Display Name:** `Хлеба и букв`
   - **Relying Party ID:** `bukleb.ru`
   - **Relying Party Origins:** `https://bukleb.ru`
4. В переменных окружения production-проекта Layero задайте:
   - `NEXT_PUBLIC_ENABLE_PASSKEYS=true`
5. Пересоберите и разверните production.

Не добавляйте preview-домен `*.layero.app` в origins для RP ID `bukleb.ru`: WebAuthn требует, чтобы origin находился на том же домене или его поддомене.

## Проверка после включения

1. Откройте `https://bukleb.ru/profile/edit` под тестовым аккаунтом.
2. Добавьте ключ доступа и проверьте, что он появился в списке.
3. Откройте сайт в другом браузере/на другом устройстве, где доступен тот же синхронизированный passkey, выйдите из аккаунта и выполните вход кнопкой **«Войти с ключом доступа»**.
4. После входа откройте настройки профиля, смените пароль и создайте новый набор резервных кодов.
5. Проверьте, что обычный вход по паролю и восстановление по резервному коду по-прежнему работают.

Рекомендуется зарегистрировать как минимум два независимых passkeys (например, телефон и менеджер паролей/второе устройство) и сохранить резервные коды отдельно.
